
# AI Automation Hub – Version 1.0

## Ziel
Eine zentrale Plattform für KI-gestützte Automatisierungen.
ChatGPT bleibt die zentrale Schnittstelle.

## Grundprinzipien
- Gesamtkosten: 0 €
- Cloudbetrieb, unabhängig vom eigenen Mac
- Keine kostenpflichtigen API-Aufrufe
- Keine Testabos oder versteckten Kosten
- Menschliche Freigabe bei externen Aktionen

## Architektur
- GitHub: Code, Daten und Dokumentation
- ChatGPT: zentrale Bedienung und Analyse
- Weitere KI-Modelle: optionale Erweiterungen
- Cloud-Ausführung: wird später anhand kostenloser Möglichkeiten geprüft
- Vercel: aktuell nicht verbunden
