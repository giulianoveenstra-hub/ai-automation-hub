# ARVO Project Update

Paths below are relative to the repository root, not the skill directory.

1. Read `ARVO-STATUS.md` first. Only open `ocs/supplier-comparison.md` for supplier details or `ocs/ocs/supplier-scoring.md` for scores.
2. Verify new claims against the user-supplied evidence or an authorized live source. Mark missing information `OPEN` / `UNVERIFIED`; never infer that a sent email has been answered.
3. Update only affected records, preserving completed work, owners, dates and decisions.
4. Resolve contradictions by correcting the relevant record, not by creating another competing summary.
5. Return a concise change summary, remaining blockers and evidence caveats. No external communication, purchase, supplier promise or production approval without authorization.
